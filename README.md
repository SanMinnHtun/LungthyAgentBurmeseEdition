## 🚀 Overview
**Lungthy Agent** is an autonomous AI system engineered to provide multi-dimensional support for individuals attempting to quit smoking[cite: 2]. Moving beyond monolithic chatbots, this system utilizes a **Hierarchical Architecture** where specialized AI agents collaborate to deliver financial, medical, and emotional insights[cite: 1, 2].

---

## 🧠 System Architecture
This project focuses on **Agentic Logic** and **Reasoning Frameworks**[cite: 1, 2]:

*   **Master Router Layer:** Performs semantic analysis of user queries to intelligently select the optimal Specialist Agent[cite: 1, 2].
*   **Specialist Agents Layer:** Individual experts with unique system instructions and toolsets[cite: 2].
*   **Orchestration Layer:** Manages complex interaction patterns, including Sequential and Parallel Workflows[cite: 1, 2].

## 🚦 How to Use
Since this repository focuses strictly on the **AI Agent Engine**, you can run it with the following steps:

1.  **Install Dependencies:**
    ```bash
    pip install agno google-adk google-generativeai notebook
    ```
2.  **Configure API Key:**
    Ensure you have a valid Google Gemini API key configured in your environment[cite: 2].
3.  **Execute the Engine:**
    Open the **Jupyter Notebook** and run the `main_loop` cells to begin interacting with the agents.
